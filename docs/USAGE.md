# 使用说明

## 画装置图

进入「装置绘图」，在左侧按分类筛选或输入器材名称。双击器材，或拖到画布中。

选中器材后，可以拖动、用控制点缩放或旋转，也可以在属性栏输入尺寸。滚轮缩放视图，平移工具用来移动画布视野。「适应图形」可以重新找到已有内容。

需要拼装时，将可连接的端口靠近，再使用连接功能。可以调整接口匹配和插入深度。若需要普通软管连接，可选软管模式。没有连接口的符号可直接自由排列。

塞子默认实心。设置孔数后，仅建立实际插入连接的位置显示孔洞；断开连接后该处恢复实心。90° 弯管保留两段直管用于插入。圆底烧瓶可切换一至四颈。

## 图片与文字

使用工具栏的图片、文字按钮插入内容。文字支持多行，双击可修改；也可以作为器材标签使用。插入的图片和文字可以移动、缩放、旋转，操作支持撤销。

图片适合补充暂时没有的仪器、板卡和传感器。请自行确认插入图片的使用权限。

## 化学工具

- 化学式页面：输入化学式，查看格式化结果、摩尔质量和组成。
- 配平页面：使用 `->` 分隔反应物和生成物，例如 `C2H5OH + O2 -> CO2 + H2O`。
- 分子结构页面：输入 SMILES，例如乙醇 `CCO`，生成二维图，切换查看三维结构。

修改反应或分子输入后，需要重新计算才能导出更新后的内容。

## 保存与输出

保存 `.chem` 文件可以保留可编辑项目。PNG 适合通用粘贴，SVG 适合矢量排版，PDF 适合打印。工具栏会按当前页面提供适用格式；分子页面还可以导出 MOL 和 SMILES。

Office 插入面向已安装的桌面版 Word、PowerPoint、Excel。应先打开目标文档，确认要插入的位置，再执行插入。不同 Office 版本对矢量图和剪贴板格式的支持可能不同，文件导出也可用于手动插入。

当前器材库用于实验报告示意，不提供设备工程尺寸、仿真结果或实验操作判断。
