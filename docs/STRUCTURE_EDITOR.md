# 结构绘制

分子结构页新增“结构绘制”视图，使用离线 Ketcher / Indigo。可在画布点选原子、拖出单/双/三键、放置环模板、编辑电荷与立体键、框选移动、删除、撤销重做和整理结构。原有 SMILES 输入、二维预览及三维构象仍保留。

顶栏提供 `.chem` 项目保存和打开。项目保存绘图的 KET、MOL、SVG 与当前视图，不把手绘图降成一个 SMILES 字符串。MOL/SDF/KET/RXN/SMILES/CML/CDXML 文件可导入；MOL、SMILES、KET、RXN 以及 SVG/PNG/PDF/HTML 按当前结构导出。反应图可输出 RXN 和图形，但不作为单个分子做三维计算。空画布或仍在更新的图不允许导出旧结果。

二维图由 Indigo 根据绘图 KET 生成，不额外执行 Open Babel 的 gen2D；绘图布局与立体信息保留在 KET/MOL。单个分子的性质和三维构象由现有 Open Babel 流程计算。不能产生三维构象的结构仍可保留、继续编辑和导出二维图。

鼠标开始修改即标记项目未保存。异步快照按载入版本和画布版本校验，旧快照不会覆盖更新的笔画。用户编辑尚未同步时禁止导出旧结构；未打开绘图页的后台 SMILES 载入不阻止已经计算完成的二维/三维结果导出。

完整离线运行需部署 `structure-editor` 目录。它包含引擎、WASM、Worker、样式和逐项依赖许可，不依赖账户、API Key 或端口服务。Ketcher 界面中常用按钮的工具提示适配为中文，化学符号保留标准表示。

测试包含真实鼠标画键与环、原子替换、撤销重做、双键和三键、手绘结构往返、立体化学、紧凑窗口、原生 WebView2、项目往返和各格式导出。物理器材的新增自绘图先独立审阅，不混入此编辑器变更。
